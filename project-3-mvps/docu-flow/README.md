# DocuFlow

**Case study + working UI** for clinical documentation workflows (structured notes, clinician review).

> Time-saved or accuracy claims are **targets / hypotheses**, not measured results.

## Working UI

[https://docu-flow-franciscos-projects-73f8717a.vercel.app/](https://docu-flow-franciscos-projects-73f8717a.vercel.app/)

## Clinical framing

Designed around documentation burden and privacy-minded processing patterns for health-system clinical workflows — not a general document editor.

## Highlights

- Structured clinical note flows
- Clinician-facing review UX
- Privacy-minded prototype framing

## Stack

React, TypeScript, Vite, Tailwind.

## Run

```bash
npm install
npm run dev
npm run build
```
