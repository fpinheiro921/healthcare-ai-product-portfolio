## Memory Update Workflow

1. Ask me: "What changed today that I should remember?"
   - Capture key learnings, decisions, or shifts
   - Ask about specific apps if relevant (HeartGuide, GlucoWise, BreathEasy, DocuFlow)

2. Based on my answer, identify which section of `.windsurf/memories.md` needs updating
   - Who I Am → identity or background changes
   - My Domain → focus or metric shifts
   - My Personas → user understanding updates
   - My Communication Rules → style changes
   - This Workspace → structural changes
   - Active Context → priority or focus shifts

3. Show me the proposed change before applying it
   - Display the current section content
   - Display the proposed new content
   - Highlight what changed and why

4. Update `.windsurf/memories.md` and confirm the save
   - Apply only the approved changes
   - Confirm which section was updated
   - Remind me to update `pm-workspace/@tasks/active.md` if priorities shifted
