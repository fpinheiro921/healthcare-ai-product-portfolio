## Context Refresh Workflow

1. Read `.windsurf/memories.md` and hold as active session context
   - Load user identity, domain, personas, and communication rules
   - Apply these constraints to all future responses

2. Open and read `pm-workspace/GOALS.md`
   - Review identity statement and quarterly OKRs
   - Note current quarter focus items

3. Open and read `pm-workspace/@knowledge/CLAUDE.md`
   - Load strategy, metrics framework, personas, glossary
   - Apply decision principles and anti-patterns
   - Note the 4 main apps: HeartGuide, GlucoWise, BreathEasy, DocuFlow

4. Open and read `pm-workspace/@tasks/active.md`
   - Review this week's top 3 priorities
   - Note blocked items and decisions needed

5. Summarize current state of work in 5 bullet points
   - What's the primary focus right now?
   - What was recently completed?
   - What's blocked or at risk?
   - What decisions are pending?
   - What should I know before starting?

6. Ask: "What do you want to work on today?"
   - Wait for user direction
   - Suggest top priority from active.md if helpful
